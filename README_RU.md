DDE Solver — учебно-исследовательское приложение для численных экспериментов с **дифференциальными уравнениями с запаздыванием (DDE)**. В нём доступны три численных метода, интерактивные графики, сравнение с точным решением, метрики погрешности, таблицы и экспорт в CSV.

Готовая Windows-сборка содержит собственную среду Java. Для её запуска не требуется отдельно устанавливать Java или Maven.

## Возможности

- Методы Эйлера, Рунге–Кутты четвёртого порядка (RK4) и Адамса–Бэшфорта второго порядка.
- Скалярные уравнения с одной или двумя постоянными задержками.
- Пользовательская функция истории \(\varphi(t)\) при \(t \le 0\).
- Линейная интерполяция задержанных значений между узлами сетки.
- Сравнение трёх методов на одном графике.
- Сравнение с заданным точным решением.
- Максимальная абсолютная, относительная, RMS и конечная погрешности.
- Четыре встроенных демонстрационных примера.
- Таблицы рассчитанных, задержанных значений и погрешностей.
- Экспорт одного или всех методов в CSV.
- Светлая и тёмная темы интерфейса.
- Валидация ввода и понятные сообщения об ошибках.
- Автоматические тесты, CI и переносимая Windows-сборка.

## Скачать

1. Откройте [последний релиз](https://github.com/Ylhh17/dde-solver/releases/latest).
2. Скачайте `DDE-Solver-1.0.0-windows-x64.zip`.
3. Полностью распакуйте архив.
4. Запустите `DDE Solver.exe` в распакованной папке `DDE Solver`.

Не отделяйте исполняемый файл от каталогов `app` и `runtime`. Переносимая сборка уже содержит необходимую среду Java.

Windows может показать предупреждение SmartScreen, поскольку приложение не подписано цифровым сертификатом. Убедитесь, что файл загружен с официальной страницы релиза этого репозитория, затем при необходимости выберите **«Подробнее → Выполнить в любом случае»**.

## Математическая модель

Приложение решает задачи с начальной историей вида

\[
y'(t) = f\!\left(t, y(t), y(t-\tau_1), y(t-\tau_2)\right), \quad t \ge 0,
\]

\[
y(t) = \varphi(t), \quad t \le 0.
\]

В интерфейсе доступны следующие шаблоны правой части:

\[
y'(t)=a\,y(t-\tau),
\]

\[
y'(t)=a\,y(t-\tau)+b\,y(t),
\]

\[
y'(t)=a\,y(t-\tau_1)+b\,y(t-\tau_2).
\]

Функция истории и точное решение вводятся в синтаксисе exp4j, например `exp(0.4*t)`.

## Быстрый пример

После запуска программы:

1. Выберите пример **«Точная: одна задержка»**.
2. Выберите метод **«Рунге–Кутты 4»**.
3. Нажмите **«Сравнить с точным»**, чтобы сопоставить численное и точное решения.
4. Откройте **«Таблица погрешностей»**, чтобы сравнить три метода.
5. При необходимости экспортируйте результаты в CSV.

## Демонстрационные задачи

| Пример | Модель | Точное решение |
|---|---|---|
| Базовая | Один задержанный член, затухающая динамика | Не задано |
| Точная: одна задержка | \(y'(t)=a\,y(t-\tau)\) | `exp(0.4*t)` |
| Точная: задержка и состояние | Задержанное и текущее значения | `exp(0.3*t)` |
| Точная: две задержки | Два задержанных значения | `exp(0.3*t)` |

## Сборка из исходников

### Требования

- JDK 24.
- Windows, Linux или macOS.
- Git необязателен, если исходный код скачан архивом.

Отдельно устанавливать Maven, JavaFX SDK и exp4j не нужно. Maven Wrapper загружает закреплённую версию Maven, после чего Maven получает зависимости проекта.

### Windows

```powershell
git clone https://github.com/Ylhh17/dde-solver.git
cd dde-solver
.\mvnw.cmd clean javafx:run
```

### Linux и macOS

```bash
git clone https://github.com/Ylhh17/dde-solver.git
cd dde-solver
./mvnw clean javafx:run
```

Если после распаковки архива у Wrapper отсутствует право на выполнение:

```bash
chmod +x mvnw
```

## Тестирование

Полный набор автоматических тестов запускается командами:

```powershell
# Windows
.\mvnw.cmd clean test
```

```bash
# Linux и macOS
./mvnw clean test
```

Тесты проверяют численное ядро, функцию истории, границы интервала, интерполяцию, ограничения параметров, валидацию ввода, аналитические задачи с одной и двумя задержками и наблюдаемые порядки сходимости.

## Windows-сборка

Переносимый образ Windows-приложения можно собрать локально, используя полный JDK 24 с утилитой `jpackage`:

```powershell
.\scripts\package-windows.ps1
```

Архив будет создан по адресу:

```text
target/distribution/DDE-Solver-1.0.0-windows-x64.zip
```

## Ограничения

- Поддерживаются только скалярные DDE.
- Уравнение может содержать одну или две положительные постоянные задержки.
- Фиксированный шаг сетки не должен превышать ни одну используемую задержку.
- Задержанные значения вычисляются линейной интерполяцией.
- График `|Эйлер − RK4|` показывает расхождение приближений, а не строгую оценку ошибки.
- Программа предназначена для обучения и предварительных численных экспериментов, а не для критически важных инженерных, клинических или производственных расчётов.
