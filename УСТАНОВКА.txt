ШЕСТОЙ ЭТАП — ПОДГОТОВКА ВЕРСИИ 1.0.0

1. Распакуйте архив во временную папку.
2. Скопируйте всё содержимое в корень проекта с заменой файлов.
   Не удаляйте каталог .git. Ничего дополнительно удалять не нужно.

3. Выполните в PowerShell из корня проекта:
   .\mvnw.cmd clean test

Ожидаемый результат:
   Tests run: 35, Failures: 0, Errors: 0, Skipped: 0
   BUILD SUCCESS

4. Запустите приложение:
   .\mvnw.cmd javafx:run

Ручная проверка:
   - выберите «Точная: одна задержка»;
   - нажмите «Сравнить методы»;
   - откройте «Таблица погрешностей»;
   - проверьте светлое и тёмное оформление;
   - выберите «Точная: две задержки» и повторите расчёт.

5. Необязательная проверка автономной Windows-сборки:
   .\scripts\package-windows.ps1

Архив приложения будет создан здесь:
   target\distribution\DDE-Solver-1.0.0-windows-x64.zip

6. Зафиксируйте этап:
   git add -A
   git commit -m "Подготовка интерфейса и релизной сборки 1.0.0"
   git push origin develop

7. Дождитесь зелёных Java CI и Windows Release.
   Windows Release можно запустить вручную во вкладке Actions.

ВАЖНО: пока не создавайте тег v1.0.0 и не сливайте develop в master.
Сначала будет отдельная финальная проверка и merge.
