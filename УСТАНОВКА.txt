ПЯТЫЙ ЭТАП — АНАЛИТИЧЕСКАЯ ПРОВЕРКА И ОЦЕНКА ОШИБКИ

1. Распакуйте архив во временную папку.
2. Скопируйте всё содержимое в корень проекта с заменой файлов.
   Ничего удалять не нужно.
3. Выполните в PowerShell из корня проекта:
   .\mvnw.cmd clean test

Ожидаемый результат:
   Tests run: 32, Failures: 0, Errors: 0, Skipped: 0
   BUILD SUCCESS

4. Запустите приложение:
   .\mvnw.cmd javafx:run

Ручная проверка точного решения:
   Тип: Классика
   a: 0.5967298790565081
   tau: 1
   h: 0.1
   t max: 1
   phi(t): exp(0.4*t)
   Точное решение: exp(0.4*t)
   Метод: Рунге-Кутты 4

Нажмите «Сравнить с точным». Должны появиться две линии и показатели ошибки.

5. После проверки:
   git add -A
   git commit -m "Добавление аналитической проверки и метрик погрешности"
   git push origin develop

6. Убедитесь, что новый запуск Java CI на GitHub зелёный.
