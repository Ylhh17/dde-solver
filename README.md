# DDE Solver

Настольное JavaFX-приложение для численного решения дифференциальных уравнений с запаздыванием (DDE), визуализации решений и экспорта результатов в CSV.

> Проект развивается на основе выпускной квалификационной работы. Сейчас выполняются ревизия численных методов, добавление автоматических тестов и улучшение интерфейса.

## Возможности

- Метод Эйлера.
- Метод Рунге — Кутты четвёртого порядка.
- Метод Адамса — Бэшфорта второго порядка.
- Уравнения с одной или двумя задержками.
- Сравнение решений на одном графике.
- Просмотр таблицы значений.
- Экспорт одного или всех решений в CSV.

## Требования

- JDK 24.
- Maven 3.9 или встроенный Maven в IntelliJ IDEA.

JavaFX SDK и `exp4j` отдельно скачивать не нужно: Maven загружает зависимости автоматически.

## Запуск

Из корня проекта:

```bash
mvn clean javafx:run
```

В IntelliJ IDEA можно открыть окно **Maven**, затем выполнить `Plugins → javafx → javafx:run`.

## Тесты

```bash
mvn test
```

## Статус

Проект находится в активной доработке. До завершения ревизии численного ядра результаты не следует использовать для критически важных инженерных расчётов.
